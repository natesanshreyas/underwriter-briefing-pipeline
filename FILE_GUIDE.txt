🔄 DATA FLOW (5 Stages)

   STAGE 1: EXTRACTION
   ───────────────────
   Input: Broker email (subject + body)
   Process: Azure Language Service + Regex patterns
   Output: 10-section structured briefing with facts & confidence
   File: underwriter_briefing.py → generate_briefing()
   Time: ~300-500ms
   Cost: $0.004/email
   
   STAGE 2: LLM NARRATIVE (New!)
   ────────────────────────────
   Input: Structured briefing JSON
   Process: OpenAI API (constrained to facts only)
   Output: 2-3 paragraph professional narrative
   File: underwriter_briefing.py → generate_narrative_wrapper()
   Time: ~1-2 seconds
   Cost: $0.008/email
   
   STAGE 3: STORAGE
   ────────────────
   Input: Briefing + narrative
   Process: Store in Cosmos DB
   Output: Persistent document with full audit trail
   File: cosmos_helper.py (create via COSMOS_COPILOT_SETUP.md)
   Time: ~100-200ms
   Cost: <$0.001/email
   
   STAGE 4: API ACCESS
   ──────────────────
   Input: HTTP GET /api/GetBriefing?email=...
   Process: Azure Function queries Cosmos DB
   Output: Formatted JSON response for applications
   File: COSMOS_COPILOT_SETUP.md Part 3 (code provided)
   Time: <1 second
   Cost: <$0.001/email
   
   STAGE 5: COPILOT DISPLAY
   ────────────────────────
   Input: API response + Power Automate flow
   Process: Format for chat display
   Output: Copilot Studio user sees briefing + narrative
   File: COSMOS_COPILOT_SETUP.md Part 4 (flow definition)
   Time: <100ms
   Cost: <$0.001/email

🔧 TROUBLESHOOTING QUICK REFERENCE

   Issue: "No secrets.json"
   └─ Create with LANGUAGE_*/OPENAI_* keys
   └─ See COSMOS_COPILOT_SETUP.md for template
   
   Issue: "LLM wrapper failed"
   └─ Check OpenAI API key is valid
   └─ Verify endpoint URL is correct
   └─ Try different model (gpt-4 if available)
   
   Issue: "Cosmos DB connection failed"
   └─ Verify connection string format
   └─ Check database/container names match
   └─ Ensure throughput provisioned (400 RU/s min)
   
   Issue: "API endpoint returns 400"
   └─ Check email parameter is passed
   └─ Verify briefing exists in Cosmos DB
   └─ Enable Function logging in Portal
   
   Issue: "Copilot doesn't show briefing"
   └─ Check Power Automate flow logs
   └─ Verify API endpoint is accessible
   └─ Test API directly: curl GetBriefing endpoint
